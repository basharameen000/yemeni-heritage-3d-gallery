# المتحف والمعرض الافتراضي التراثي اليمني ثلاثي الأبعاد 🏛️🇾🇪
## Ancient Yemeni Heritage 3D Virtual Gallery & Museum

معرض ومتحف افتراضي تفاعلي ثلاثي الأبعاد (WebGL / Three.js) يجسد الهوية المعمارية والتراثية اليمنية الأصيلة بروح تاريخية عتيقة، ويحتوي على قاعة عرض فخمة تضم 11 عملاً فنياً ولوحة تراثية بجودة 8K وأبعاد متحفية عملاقة.

---

## 🌟 مميزات المشروع (Key Highlights)

### 1. العمارة التراثية اليمنية العتيقة (Vernacular Yemeni Architecture)
* **جدران حجر الحبش والبلق:** مداميك حجرية بازلتية قديمة بمونة الطين وملمس خشن يحاكي قلاع وحصون اليمن التاريخية.
* **العقود الحجرية المهيبة (Stone Arcade Arches):** رواق أوسط بأقواس حجرية نصف دائرية ودعامات حجرية ضخمة بنقوش هندسية يمانية.
* **سقف الجذوع الريفي (Timber Trunk Ceiling):** جذوع أشجار السدر والعلب الطبيعية المستديرة مع عوارض خشبية ثقيلة.
* **أشعة الشمس الحجمية (Volumetric God Rays):** إضاءة شمسية ناعمة تخترق كوات النوافذ العلوية بزوايا مائلة لإنارة الرواق الحجري.

### 2. الأركان والأدوات الحرفية والريفية (Cultural Artifacts)
* **ركن التنور وموقد النار:** تنور طيني مخروطي مع وهج نار دافئ وبجانبه ضمة سنابل القمح والذرة الذهبية.
* **الرحى البازلتية الحجرية:** مطحنة حبوب يمنية تقليدية من حجر الحبش الأسود بمقبض خشبي على قاعدة خشبية.
* **الجرار الفخارية الأصيلة:** تشكيلة من أواني الفخار (الزير، الشربة، الحيسية) موزعة في الأركان وداخل روازين حجرية غائرة.
* **حصر وأطباق الخوص المجدولة:** مسارات مفروشة بحصر سعف النخيل وأطباق دائرية ملونة (المناسف والمصارف) مسندة للأعمدة.

### 3. ديوان المفرج الصنعاني (The Sana'ani Mafraj)
* **القمريات المضيئة المعشقة:** نوافذ قمرية نجمية ملونة بأسلوب العمارة الصنعانية الفريد.
* **الجلسة التراثية وسجاد الكليم:** أفرشة ومساند ومتاكي بنقوش هندسية عنابية أصيلة.
* **المداعة النحاسية وفوانيس القاز:** مداعة صنعانية معرقة مع فوانيس كيروسين بلهب ذهبي متحرك.

### 4. اللوحات والصور التراثية الـ 11 (Grand Artworks Display)
* معروضة بأبعاد متحفية كبيرة **(3.75م × 2.50م)** وبورتريه صدارة مركزي **(3.20م × 3.20م)**.
* حدة بصرية فائقة بتقنية ترشيح الأنسجة `texture.anisotropy = 16` مع إطارات خشبية مذهبة وبطاقات نحاسية.
* نافذة فحص تفاعلية (Click-to-Inspect Modal) تكبّر كل لوحة بدقة 8K كاملة مع بطاقتها التوثيقية والبيئية.

## 🎮 التحكم والتجوال (Controls)

| الإجراء | زر التحكم | الوصف |
| :--- | :---: | :--- |
| **توجيه الكاميرا** | الفأرة (Mouse) | انقر داخل الصالة لتحريك زاوية الرؤية الحرة 360 درجة |
| **الحركة والمشي** | `W, A, S, D` أو الأسهم | التجوال والمشي داخل الأروقة وبين الأعمدة الحجرية |
| **فحص اللوحات** | النقر الأيسر (Left Click) | فتح نافذة التكبير العالية الدقة وبطاقة الشرح الأكاديمي |
| **إغلاق النافذة** | `ESC` أو زر (X) | العودة للمشي والتجوال الحر |
| **الجولة الإرشادية** | زر `Guided Tour` | تشغيل جولة سينمائية تلقائية تنتقل بك بين اللوحات |
| **الصوت المحيطي** | زر `Audio` | تشغيل الموسيقى التراثية الهادئة |
| **الخريطة المصغرة** | زر `Minimap` | عرض خريطة تفاعلية للموقع الحالي والاتجاه داخل المعرض |

## 🚀 كيفية التشغيل محلياً (Run Locally)

المشروع مصمم ليعمل مباشرة عبر أي متصفح حديث يدعم WebGL:

```bash
# 1. الاستنساخ من GitHub
git clone https://github.com/basharameen000/yemeni-heritage-3d-gallery.git
cd yemeni-heritage-3d-gallery

# 2. تشغيل سيرفر محلي فوري (باستخدام بايثون)
python -m http.server 8080

# 3. افتح المتصفح على:
# http://localhost:8080
```
